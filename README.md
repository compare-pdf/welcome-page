# Welcome Page for Your Extension

This is a simple welcome page for your browser extension, designed to be hosted on GitHub Pages.

## How to Customize

1.  **Edit `index.html`**:
    *   Replace `"Your Extension Name"` with the actual name of your extension.
    *   Update the links in the navigation if needed.
    *   Change the main heading and instructional text to match your extension's functionality.

2.  **Replace Images**:
    *   Create two PNG files: `step-1.png` and `step-2.png`.
    *   `step-1.png` should demonstrate how to pin the extension in the browser.
    *   `step-2.png` should show how to open/use the extension.
    *   Place these files in the `docs/images/` directory.

3.  **Customize Styles (`style.css`)**:
    *   Feel free to change the color scheme, fonts, or layout in `style.css` to better match your brand. The primary color is `#4A90E2`.

## How to Deploy to GitHub Pages

1.  **Push to GitHub**: Make sure your code is pushed to a GitHub repository.
2.  **Enable GitHub Pages**:
    *   Go to your repository's **Settings** tab.
    *   In the "Code and automation" section of the sidebar, click on **Pages**.
    *   Under "Build and deployment", for the **Source**, select **Deploy from a branch**.
    *   Under "Branch", select your branch (e.g., `main` or `master`) and choose the `/docs` folder.
    *   Click **Save**.
3.  **Done**: Your page should be live in a few minutes at `https://<your-username>.github.io/<your-repo-name>/`.
